⚠️ Speech Not Working? Troubleshooting

If you see "synthesis-failed" errors:

  1. Browser: Use Google Chrome (best support)
  2. Windows: Settings → Ease of Access → Narrator → Turn ON
  3. Mac: System Preferences → Accessibility → Speech → Enable
  4. Try: Restart browser completely
  5. Alternative: Disable "Speech Output" toggle (visual mode only)

Note: Some systems don't support browser TTS. The app still works perfectly without speech - you'll see all translations and completions visually.
